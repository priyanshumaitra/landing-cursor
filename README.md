# Cursor - Landing Page
Landing page of cursor using raw HTML and CSS

[Live Link](https://priyanshumaitra.github.io/landing-cursor/)

### Run locally

Open Directly in Browser (Simplest)

Clone the repository:

```
git clone https://github.com/priyanshumaitra/landing-cursor.git

cd landing-cursor
```

1. Open index.html directly in your browser:
2. Double-click `index.html`, or
3. Right-click → Open with browser


**VS Code (Live Server extension)**

1. Install “Live Server”
2. Right-click `index.html` → **Open with Live Server**
